Nexa TalentOS | Employee Skill Evaluation & Promotion Readiness Platform

Developing a full-stack talent management platform that helps managers evaluate engineer competencies, identify skill gaps, and assess promotion readiness through structured capability assessments and interactive visualizations.

Key Features & Technical Contributions

* Backend Development: Built RESTful APIs using Java 17 and Spring Boot 3 to support authentication, engineer profile management, and capability evaluations.
* Authentication & Security: Implemented JWT-based authentication with Spring Security to secure API endpoints and manage authenticated access.
* Database Integration: Integrated Spring Data JPA and Hibernate for data persistence, supporting PostgreSQL and an in-memory H2 database for local development and testing.
* Engineer Management: Developed functionality to create and retrieve engineer profiles.
* Capability Assessments: Implemented evaluation workflows to submit capability scores and maintain assessment snapshots.
* Interactive Dashboard: Developed a React dashboard with radar charts to visualize engineer skill levels, highlight competency gaps, and support promotion-readiness assessments.
* Frontend Development: Built the user interface using React, TypeScript, and Vite, with Recharts for data visualization.
* Build & Configuration: Configured Maven-based backend builds and environment-specific application settings.

Technology Stack: Java 17, Spring Boot 3, Spring Security, JWT, Spring Data JPA, Hibernate, PostgreSQL, H2, React, TypeScript, Vite, Recharts, Maven, REST APIs, Git.

Project Repository: https://github.com/Someshdiwan/NexaTalent

Objective: To provide a structured, data-driven approach to employee skill evaluation, competency-gap analysis, and promotion-readiness assessment.
